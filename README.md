# WinSwitcher

macOS 原生窗口切换器（Swift + AppKit + SwiftUI），一比一还原 **Windows 11 Alt+Tab** 的窗口级切换动作、MRU 展现顺序与视觉交互。

## 核心特性

- **1:1 Windows 窗口级 MRU 展现顺序**
  - 按每个独立顶层窗口的最近激活时间（MRU）排序，同应用多窗口独立排位。
  - 触发瞬间默认选中第 2 个窗口（索引 `1`），支持 A ⇄ B 极速乒乓切换；当桌面或无窗口应用获焦时，自动选中第 1 个窗口（索引 `0`）。
  - 按住修饰键期间窗口顺序完全冻结，松开才提交切换并将目标置顶；按 `Esc` 或点击面板外取消时不改动顺序。
  - **快切防闪烁**：默认 `120 ms` 延迟内快速按放直接切换，不闪出面板；按第二次 `Tab` 或方向键立即展开面板。
- **最小化 / 隐藏窗口沉底（Windows 标准逻辑）**
  - 最小化与 `Cmd+H` 隐藏的窗口保留在列表中，选中即自动还原并聚焦。
  - 主动最小化或隐藏时自动沉底至队列末尾，避免紧接着 `Alt+Tab` 又切回刚刚收起的窗口。
- **跨所有桌面与全屏 Space 统一列表**
  - 通过 SkyLight + Accessibility 跨 Space 枚举所有普通桌面与全屏 Space 的窗口，并支持显示空间角标（`D2` / `全屏`）。
  - 选中跨 Space 窗口后自动切换到对应空间并**单窗口独立置顶**（不连带拉起同应用其他窗口）。
- **防卡死与热键冲突保护（架构级安全加固）**
  - **独立实时 EventTap 线程**：不占用主线程、绝不拦截鼠标事件、回调内零 IPC/AppKit 阻塞（< 50 微秒返回）。
  - **全异步 AX 扫描 + 150ms 超时**：杜绝任何卡顿/模态窗口拖死主线程或 WindowServer。
  - **连续超时自动熔断（Circuit Breaker）**：若 10 秒内连续触发 2 次超时，永久停用拦截并通知用户，绝不对抗系统保护。
  - **实时热键冲突检测（`CGGetEventTapList`）**：自动识别正在主动拦截键盘的第三方程序（如 AltTab、Karabiner、Raycast、BetterTouchTool 等），在设置页与菜单栏高亮提示。
  - **智能透传**：自动检测系统安全输入模式（`IsSecureEventInputEnabled()`），并在「系统设置」及远程桌面/虚拟机等排除应用中自动放行快捷键。
  - **紧急退出热键**：任何时候按下 `Ctrl + Option + Command + Esc` 可在独立线程立即释放拦截并强制退出。

## 构建、测试与安全运行

```bash
# 运行单元测试（MRU 排序引擎 + 熔断保护逻辑）
swift test

# 编译 Release 版本并打包签名 WinSwitcher.app
./scripts/build-app.sh release

# 调试阶段推荐：带看门狗自动退出保护的启动方式（默认 120 秒后自动退出，按 Ctrl+C 取消）
./scripts/run-safe-dev.sh 120

# 确认稳定后正常启动
open build/WinSwitcher.app
```

首次启动后，请在偏好设置中授予两项 macOS 权限：
1. **辅助功能（必需）**：用于全局快捷键拦截、实时追踪窗口焦点/最小化事件及单窗口置顶。
2. **屏幕录制（推荐）**：用于在 Windows 11 卡片中渲染窗口实时缩略图与最小化前缓存帧。
